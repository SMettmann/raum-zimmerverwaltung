# RAUMWERK – Raum- & Zimmerverwaltung

V1-Prototyp einer bewusst sehr einfach bedienbaren Raum- und Zimmerverwaltung.

## Aktuell nutzbar

- Dashboard mit Tagesübersicht
- Monatskalender und Buchungsliste
- Buchungen anlegen, bearbeiten, stornieren/löschen
- automatische Prüfung auf Doppelbelegung
- Räume und Zimmer anlegen/bearbeiten
- Gäste und Kunden verwalten
- Reinigungsstatus pro Raum
- Aufgabenverwaltung
- Buchungsbestätigung druckbar / als PDF speicherbar
- CSV-Export der Buchungen
- lokale Datensicherung und Wiederherstellung
- responsive Bedienung für Desktop und Smartphone

> Technischer V1-Stand: Daten werden aktuell lokal im Browser gespeichert. Mehrbenutzerbetrieb, Login, zentrale Datenbank und echte Kalender-/E-Mail-Integrationen folgen als nächste Ausbaustufe.
